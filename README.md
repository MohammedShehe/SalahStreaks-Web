# SalahStreaks Website

Static, serverless website for SalahStreaks.

## Files
- `index.html` — public landing page
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `support.html` — support/contact
- `styles.css` — shared responsive styling
- `robots.txt` — crawler rules
- `sitemap.xml` — sitemap template

## Publish
Upload the folder to any static host such as GitHub Pages, Cloudflare Pages, Netlify, Vercel, or ordinary web hosting.

Before publishing, replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with the real website domain.
